## Why

The dashboard needs a coherent first product slice for cataloging current and historical development projects as a private, local portfolio. It should support quick technical discovery and editorial presentation of curated project media without exposing source code or private data.

## What Changes

- Add a local editorial dashboard, catalog, project detail pages, and local administration.
- Support public GitHub/Trello display links, curated local media with originals, and manual milestones.
- Exclude mobile, automatic synchronization, source-code browsing, authentication, and remote hosting from the initial release.

## Capabilities

### New Capabilities
- `editorial-project-catalog`: Dashboard, catalog, detail pages, media, and public links.
- `local-project-administration`: Local project and media management without authentication.
- `manual-project-history`: User-authored project milestones.
- `privacy-safe-project-data`: Boundaries excluding source and private data.

### Modified Capabilities
- None.

## Impact

Future Next.js, Go, SQLite, and local media behavior. Reference repositories remain read-only and only safe, explicitly curated metadata may be used.
